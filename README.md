# chageun-docs

차량용 운전 학습 앱 **차근**의 2026 현대자동차그룹 차량용 앱 개발 공모전 준비 문서 저장소입니다.

## 차근 소개

**차근 — 내 차 안의 다정한 운전 튜터**

면허는 있지만 운전이 낯선 사람을 위해, 내 차와 자주 다니는 길에서 운전·주차를 차근차근 익히도록 돕는 차량용 앱입니다. 출발 전 연습 계획부터 주행·주차 후 복습까지 차량의 조작과 기록을 연결하며, 스마트폰이나 추가 장비 없이 차량 안에서 이용을 마치는 것을 목표로 합니다.

## 핵심 기능

현재 공모전 기획 단계이며, 아래 기능은 개발 예정입니다.

| 기능 | 내용 |
|---|---|
| 다정한 운전 튜터 | 숙련도와 어려워하는 부분에 맞춰 오늘의 연습을 제안하고, 익숙해질수록 안내를 줄입니다. |
| 내비 연동·주행 비교 | 목적지·길안내와 연습을 연결하고, 같은 길의 이전 기록을 비교해 다음 연습에 반영합니다. |
| 주차 코치 | 정차 중 주차 원리를 익히고, 후진주차·평행주차 등의 조작 기록을 주차 후 복습합니다. |
| 항목별 숙련도 | 검증된 기준과 지원되는 차량 기록을 바탕으로 항목별 숙련도(0~10)를 추정하고, 기록이 부족하면 ‘평가 중’으로 표시합니다. |
