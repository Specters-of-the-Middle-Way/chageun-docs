# chageun-docs

차량용 운전 학습 앱 **차근**의 2026 현대자동차그룹 차량용 앱 개발 공모전 준비 문서 저장소입니다.

## 차근 소개

**차근 — 내 차 안의 다정한 운전 튜터**

면허는 있지만 운전이 낯선 사람을 위해, 내 차와 자주 다니는 길에서 운전·주차를 차근차근 익히도록 돕는 차량용 앱입니다. 출발 전 연습 계획부터 주행·주차 후 복습까지 차량의 조작과 기록을 연결하며, 스마트폰이나 추가 장비 없이 차량 안에서 이용을 마치는 것을 목표로 합니다.

## 핵심 기능

현재 공모전 기획 단계이며, 아래 기능은 개발 예정입니다.

| 기능 | 내용 |
|---|---|
| 다정한 운전 튜터 | 숙련도와 어려워하는 부분에 맞춰 오늘의 연습을 제안하고, 익숙해질수록 안내를 줄입니다. |
| 내비 연동·주행 비교 | 목적지·길안내와 연습을 연결하고, 같은 길의 이전 기록을 비교해 다음 연습에 반영합니다. |
| 주차 코치 | 정차 중 주차 원리를 익히고, 후진주차·평행주차 등의 조작 기록을 주차 후 복습합니다. |
| 항목별 숙련도 | 검증된 기준과 지원되는 차량 기록을 바탕으로 항목별 숙련도(0~10)를 추정하고, 기록이 부족하면 ‘평가 중’으로 표시합니다. |

## 앱 사용 흐름

[차근 상세 플로우차트](차근_상세_플로우차트.pdf)를 기준으로 정리한 흐름입니다. 정차용 가상 연습과 실주행 코칭 설계를 구분하며, 실주행 적용은 기능 허용과 입력 검증을 전제로 합니다.

1. **출발 준비**: 정차 중 연습할 내용과 안내량을 선택하고, 기록 동의·기능 허용·입력 상태를 확인해 운전 세션을 시작합니다.
2. **주행 상황 관찰**: 출발·회전·차로 변경·합류 등의 상황을 관찰하고, 동시에 발생한 이벤트는 중복 안내가 없도록 정리합니다.
3. **필요한 안내·기록**: 허용된 준비 구간에서 짧게 안내합니다. 차량 경고·내비·안내 중지 요청을 우선하고, 입력이 부족하면 판단을 보류합니다.
4. **주차 확인·세션 종료**: 주차 완료와 사용 허용 상태를 확인한 뒤 사용자 선택으로 세션을 마칩니다. 목적지 도착이나 일시 정지만으로 복습 화면을 열지 않습니다.
5. **복습·다음 연습**: 확인된 사실과 미확인을 나눠 보고, 운전자가 원하면 상황을 설명합니다. 정차용 짧은 연습으로 연결하고 다음 추천·안내량에 반영합니다.
